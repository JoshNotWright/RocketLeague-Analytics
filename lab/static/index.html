Jobs

Two kinds of job. A crawl fetches replays on a Hetzner box: start one and a box is created for it, stop it and the box is pushed, validated and deleted, continue it and a new box resumes from the ledger. A build runs on the lab and turns the archive into the model tables, window by window, only for what is new.

    Transfers
    The box ships decoded replays in batches. Each batch travels through four stages and nothing on the box is deleted until the lab has confirmed it.
    
      
    
        
    1 · SealedThe box closes a batch and writes a manifest with every id, size and hash.
    
        
    2 · PushedDecoded files, the ledger and the manifest are copied to the lab over the tailnet.
    
        
    3 · ValidatedThe lab re-hashes every file on its own disk and checks the ledger; it writes an OK or a BAD mark.
    
        
    4 · CleanedOnly after the OK does the box delete that batch's raw and decoded files.
    
      
    
      
    
      
    Batches newest first

      Secrets
      These live only in /etc/rlreplay/lab.env on the lab. The page can tell whether each is set, never what it is. A box receives them over SSH when it is created and never writes them anywhere a snapshot or log could keep.
      
          
      Lab
      
          
      First run
      1. Fill the three secrets in the env file.
      2. Rebuild the image once.
      3. On Jobs, create the Smoke test preset and start it.
      4. Watch its first batch validate, then stop it; the box is deleted for you.
      5. Create the Full crawl and start it.
      6. When replays have landed, create a Build tables job; run it again whenever the archive has grown.
